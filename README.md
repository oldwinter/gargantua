# GARGANTUA · 卡冈图雅黑洞引力透镜实时模拟器

> 本项目代码由 **gemini 4 argon** 生成。

基于 Three.js 与 WebGL 广义相对论零测地线光线步进（Geodesic Raymarching）着色器制作的《星际穿越》卡冈图雅（Gargantua）黑洞实时可视化网页。

## 启动方式

```bash
npm start
```

默认监听 `http://127.0.0.1:8080`。仓库已内置 `vendor/three.module.min.js`，无需额外联网加载 CDN，也可使用任意静态 HTTP 服务器直接托管当前目录。

## 核心效果与物理模型

- **广义相对论引力透镜与克尔自旋拖拽**：对每个像素沿弯曲时空积分零测地线偏折方程 `a = -1.5 * Rs * h^2 * x / r^5 + a_Kerr`，黑洞背面的吸积盘光线经强引力场弯曲后向上、向下包络事件视界阴影，形成上下双光环结构与紧贴视界边缘的内光子环（Photon Ring）。
- **差动旋转等离子体吸积盘**：采用双相位平流（Dual-Phase Advection）湍流与 Novikov-Thorne 径向辐射通量分布，消除极角接缝并呈现内快外慢的开普勒剪切旋转与暗磁隙环带。
- **相对论多普勒聚束与黑体辐射谱**：支持在电影暖金对称美学与基普·索恩相对论强蓝移/红移非对称模式之间连续过渡，色温覆盖 `2200 K` 至 `14000 K`。
- **等角立方体天球星场与星云透镜畸变**：采用无极点奇异性的等角立方体投影（Equi-angular Cubed-Sphere）生成多层恒星与银河尘埃带，背景星光掠过光子球层时实时呈现爱因斯坦环拉伸与增亮效应。
- **IMAX 电影级光学后处理**：包含高亮提取、各向同性高斯散射辉光（Bloom）、IMAX 变形宽银幕横向眩光（Anamorphic Flare）以及色度保持的 ACES 色调映射。

## 交互控制

- **左键拖拽**：360° 环绕黑洞旋转观察
- **滚轮缩放**：平滑拉近或推远观测距离（左下角实时计算当前轨道的广义相对论引力时间膨胀率 `dτ/dt`）
- **右键拖拽（或 Shift + 左键拖拽）**：调整银幕镜头倾角（Roll）
- **双击画面**：平滑复位至《星际穿越》经典视角
- **右侧控制面板**：内置 6 套场景预设（`星际穿越·经典`、`索恩相对论模式`、`爱因斯坦环俯视`、`掠过光子球层`、`高能蓝巨类星体`、`纯引力透镜黑洞`）与 21 项实时可调参数。
